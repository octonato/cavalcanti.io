This talk explores techniques for building a DDD/CQRS application with Scala and Akka. It first uses the Scala type system and functional programming to build a domain model from case classes. It then integrates that model with Akka and Akka Persistence. Topics include Akka as a messaging subsystem, reliable event propagation from the command side to the query side, failure recovery, and asynchronous programming. It ends with a demo application built on Play and Akka.

Recorded at Devoxx Belgium 2015.
