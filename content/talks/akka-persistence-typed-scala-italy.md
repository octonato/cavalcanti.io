This talk introduces the new typed API for Akka Persistence and its integration with Akka Cluster Sharding. Type safety is the headline feature, but the new API brings more than types. It also includes API changes that help you write better and safer persistent actors. The talk covers the pitfalls of the untyped API and how the typed API solves them.

Recorded at Scala Italy 2019.
