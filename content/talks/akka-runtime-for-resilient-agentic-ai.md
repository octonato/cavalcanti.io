Chaining LLM calls works for a prototype, but long-running agentic workflows break under crashes, interruptions, and network failures. This talk shows how Akka workflows give agents durable execution. Each step runs only once, which saves tokens and recovery time. Built-in session memory lets agents reason, remember, and act reliably at enterprise scale.

Recorded at Devoxx Belgium 2025.
