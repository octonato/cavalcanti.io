Some developers find event sourcing too hard. Others find it simple. Event sourcing lets you model your business as events (facts) instead of only state. Applying it means learning to think differently about modelling, consistency and transactions in distributed systems. This talk covers patterns and techniques for writing event-sourced applications with the building blocks of the Akka Platform.

Recorded at ScalaCon 2021.
